# Test data

`enterprise-attack-subset.json` is a subset of
[Enterprise ATT&CK 19.2](https://github.com/mitre-attack/attack-stix-data/tree/v19.2/enterprise-attack),
as published in STIX 2.1: nine techniques, among them a revoked and a
deprecated one, their tactics, the detection strategies that detect them,
and their analytics, with every data component of the version, so that the
names source definitions declare can be checked. Descriptions, references
other than ATT&CK's own, and the log sources of data components no analytic
here reads were removed; everything else is as published.
