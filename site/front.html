An open security data platform, measured at every step

Logs come in over the network, become OCSF events, and are stored and searched in ClickHouse. Indicators from threat intelligence feeds are matched against every event as it arrives, and Sigma rules are evaluated by an engine that is checked against a reference on every event.

The path of an event

Each step is a role of one binary. They run in one process on a laptop, or apart, with Kafka between them.

  1. SourcesSysmon, Windows Security, auditd, Falco, cloud, Zeek, Suricata
  2. ReceiverHTTP, syslog over TLS, OpenTelemetry; acknowledged once it cannot be lost
  3. NormalizerTo OCSF by a declarative definition, dropping nothing
  4. Event topicOrdered, bounded, read by each role at its own pace
  1. WriterBatches into ClickHouse; a record delivered twice is stored once
  2. SearchBy time, class, and any OCSF attribute, in the browser and over HTTP
  1. DetectorMatches indicators beside storage, and never slows it
  2. FindingsEach match stored beside its event, with every feed that asserts it
